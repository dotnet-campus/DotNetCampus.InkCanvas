# 笔迹美化算法完全实现详解

> 本文描述的是一个纯二维几何、平台无关的实时笔迹美化算法。输入是按时间到达的指针采样点，输出是可直接填充的一个或多个多边形轮廓。实现不依赖 Avalonia、WPF、WinUI、Android、iOS、Canvas、Skia 或任何特定图形 API。
>
> 本文按照当前实现的真实行为整理。只要完整实现本文中的数据结构、状态机、公式、几何函数和边界修复规则，即可复现该算法。

## 1. 算法目标

算法把离散输入点转换为具有以下特征的笔迹：

1. 低速变粗、高速变细；
2. 可选地融合压感；
3. 对速度和宽度做递推平滑；
4. 使用二次 Bézier 曲线生成平滑中心线；
5. 使用固定笔帽模板沿中心线扫掠，生成闭合轮廓；
6. 修复急转弯、回环、自重叠和局部漏填；
7. 对点击、两点短划、普通长笔迹分别处理；
8. 支持多个 `strokeId` 同时存在，彼此状态隔离；
9. 增量输出当前笔迹的最新完整几何。

算法坐标单位可以是像素、DIP、毫米或任意统一单位；时间戳单位必须与配置的时间单位一致。当前默认参数按“坐标近似像素、时间戳为毫秒”设计。

## 2. 输入、输出与配置

### 2.1 输入点

每个输入点包含：

```text
InputPoint
    position: Point2D
    timestamp: integer
    pressure: real
    strokeId: integer
    status: Down | Move | Up
```

约束：

- `position.x`、`position.y` 必须是有限数；
- `pressure` 必须是有限数；
- 同一笔内时间戳应单调递增；
- 同一 `strokeId` 必须先收到 `Down`，随后才处理 `Move`/`Up`。

### 2.2 输出结果

```text
BeautifierResult
    strokeId: integer
    outline: List<Point2D>
    outlines: List<List<Point2D>>
    isCompleted: boolean
    wasAccepted: boolean
```

语义：

- `outline`：兼容性完整轮廓。它可能是带桥接边的非简单多边形，应使用**非零环绕规则**填充；
- `outlines`：推荐直接填充的扫掠单元集合；普通长笔迹通常包含多个凸多边形，可逐个填充；
- `isCompleted`：当前输入是否为 `Up`；
- `wasAccepted`：当前输入是否进入了笔迹状态；
- `Down` 被接受，但不立即产生轮廓；
- 未找到对应状态的 `Move`/`Up` 返回空轮廓且 `wasAccepted=false`；
- 无论 `Up` 最终是否被采纳，都要删除该 `strokeId` 的状态。

轮廓点列表不需要重复首点。绘制时用“闭合路径”连接末点与首点。

### 2.3 配置

```text
Options
    maximumWidth = 12
    velocityResponse = 2
    minimumTimeInterval = 7
    minimumDistance = 2
    pressureInfluence = 0
```

验证规则：

- `maximumWidth`：有限且大于 0；
- `velocityResponse`：有限且不小于 0；
- `minimumTimeInterval`：有限且不小于 0；
- `minimumDistance`：有限且不小于 0；
- `pressureInfluence`：有限且位于 `[0, 1]`。

其他固定常量：

```text
MINIMUM_WIDTH_RATIO = 0.2
MINIMUM_TEMPLATE_ARC_TURN = 0.05
MINIMUM_TEMPLATE_ARC_ALIGNMENT = -0.9
GEOMETRY_EPSILON_SQUARED = 1e-12
INTERSECTION_PARALLEL_EPSILON = 1e-9
INTERSECTION_ENDPOINT_TOLERANCE = 1e-6
SAMPLE_DUPLICATE_DISTANCE = 0.01
```

## 3. 内部状态与基础类型

### 3.1 二维点和向量运算

`Point2D(x, y)` 同时作为点和向量使用。

```text
distance(a, b) = sqrt((a.x-b.x)^2 + (a.y-b.y)^2)
distanceSquared(a, b) = (a.x-b.x)^2 + (a.y-b.y)^2
lerp(a, b, t) = a + (b-a)*t
dot(a, b) = a.x*b.x + a.y*b.y
cross(a, b) = a.x*b.y - a.y*b.x
cross(origin, a, b) = cross(a-origin, b-origin)
negate(v) = (-v.x, -v.y)
```

归一化方向：

```text
direction(a, b):
    d = b-a
    length = |d|
    if length < 1e-6: return (1, 0)
    return d/length
```

线段左法向：

```text
segmentNormal(a, b):
    d = b-a
    length = |d|
    if length < 1e-6: return (0, 1)
    return (-d.y/length, d.x/length)
```

### 3.2 内部点

```text
RawPoint
    position: Point2D
    timestamp: integer
    rawSpeed: real
    smoothSpeed: real
    rawHalfWidth: real
    halfWidth: real
```

### 3.3 单笔状态

```text
StrokeState

    samples: List<RawPoint>
    outline: List<Point2D>
    outlines: List<List<Point2D>>
```

## 4. 总处理流程

```text
process(input):
    validate input

    if input.status == Down:
        states[input.strokeId] = new StrokeState(input)
        return Result(input.strokeId, [], [], false, true)

    if states 不包含 input.strokeId:
        return Result(
            input.strokeId,
            [],
            [],
            input.status == Up,
            false)

    stroke = states[input.strokeId]
    accepted = tryAddPoint(stroke, input)

    if accepted:
        geometry = buildGeometry(stroke, input.status == Up)
    else:
        geometry = (stroke.outline, stroke.outlines)

    stroke.outline = geometry.outline
    stroke.outlines = geometry.outlines

    completed = input.status == Up
    if completed:
        remove states[input.strokeId]

    return Result(
        input.strokeId,
        geometry.outline,
        geometry.outlines,
        completed,
        accepted)
```

`Reset` 只需清空状态表。

## 5. 输入点过滤、速度与宽度

这是算法的第一核心阶段。

### 5.1 初始量

```text
last = stroke.rawPoints.last
distance = |input.position - last.position|
elapsed = input.timestamp - last.timestamp
isUp = input.status == Up
isShortStrokeUp = isUp and stroke.rawPoints.count <= 2
position = input.position
```

### 5.2 普通移动点的早期拒绝

若不是 `Up`，满足任一条件立即拒绝：

```text
elapsed < minimumTimeInterval
distance < machine epsilon
```

注意：此处只检查“时间过短或完全不移动”。稍后还会联合检查最小距离。

### 5.3 零距离抬笔

若 `isUp` 且 `distance < machine epsilon`：

1. 当前只有一个原始点：认定为点击，设置 `isTap=true`，返回接受；
2. 当前有两个原始点：直接返回接受，不新增点；
3. 当前已有至少三个原始点，且 `elapsed > 20`：拒绝这个 `Up`；
4. 否则外推一个虚拟尾点：

```text
previous = rawPoints[count-2]
position = last.position + 0.6 * (last.position - previous.position)
distance = distance(last.position, previous.position)
```

该规则避免快速抬笔时设备上报同坐标，导致笔迹末端停在最后一个中心点内部。

### 5.4 尾锋判定

```text
isTail(narrowPointCount, previous, current, isUp):
    if not isUp: return false
    angleDegrees = atan2(current.y-previous.y, current.x-previous.x) * 180/pi
    upward = -155 < angleDegrees < -35
    return narrowPointCount >= 3 or (upward and narrowPointCount >= 2)
```

这是带方向偏好的书写尾锋启发式规则：连续窄点足够多时，允许非常近的抬笔点进入；向上方向可少一个窄点。

### 5.5 最小距离和时间联合过滤

```text
if (distance < minimumDistance or elapsed < minimumTimeInterval)
   and not isShortStrokeUp
   and not isTail:
    reject
```

随后若 `elapsed <= 0`，拒绝。

### 5.6 速度与慢速抬笔过滤

```text
speed = distance / elapsed
```

若为非短笔迹 `Up` 且：

```text
speed < 0.03
```

则拒绝。它用于避免长时间停笔后抬起产生肥厚或异常尾端。

### 5.7 压感归一化

只有 `0 < pressure <= 1` 时采用输入值，否则使用 `0.5`：

```text
p = pressure if 0 < pressure <= 1 else 0.5
```

### 5.8 速度映射到宽度

```text
velocityWidth = maximumWidth * exp(-velocityResponse * speed)
pressureScale = 1 - pressureInfluence
                + pressureInfluence * p * 2
width = clamp(
    velocityWidth * pressureScale,
    maximumWidth * 0.2,
    maximumWidth)
halfWidth = width / 2
```

性质：

- `velocityResponse=0` 时速度不影响宽度；
- `pressureInfluence=0` 时忽略压感；
- `pressureInfluence=1` 时压感比例为 `2p`；
- 最终全宽不低于最大宽度的 20%；
- 所有后续几何都使用半宽。

新增：

```text
point = RawPoint(position, timestamp, speed, speed, halfWidth, halfWidth)
rawPoints.append(point)
```

### 5.9 抬笔宽度突增限制

若新增的是 `Up` 点且现在点数大于 2：

```text
maximumHalfWidth = previous.halfWidth * 1.3
if current.halfWidth > maximumHalfWidth:
    current.rawHalfWidth = maximumHalfWidth
    current.halfWidth = maximumHalfWidth
```

这可防止抬笔事件速度骤降造成尾端突然变粗。

### 5.10 第一个点回填

当原始点数首次达到 2 时，把第二点的速度和宽度复制到第一点：

```text
rawPoints[0].rawSpeed = rawPoints[1].rawSpeed
rawPoints[0].smoothSpeed = rawPoints[1].smoothSpeed
rawPoints[0].rawHalfWidth = rawPoints[1].rawHalfWidth
rawPoints[0].halfWidth = rawPoints[1].halfWidth
```

否则起点会保留零宽。

## 6. 速度与宽度平滑

### 6.1 当前速度平滑

仅修改最新点：

```text
count == 2:
    s1 = 0.6*r0 + 0.4*r1

count == 3:
    s2 = 0.3*s0 + 0.3*s1 + 0.4*r2

count >= 4:
    sLast = 0.1*s[-4] + 0.2*s[-3] + 0.3*s[-2] + 0.4*r[-1]
```

其中 `r` 为 `rawSpeed`，`s` 为 `smoothSpeed`。当前几何主要使用宽度，平滑速度被保留用于扩展和诊断。

### 6.2 当前宽度平滑

若当前点不是尾锋：

```text
count == 2:
    h = 0.6*rawHalfWidth[0] + 0.4*rawHalfWidth[1]
    halfWidth[0] = h
    halfWidth[1] = h

count == 3:
    halfWidth[2] = 0.3*halfWidth[0]
                 + 0.3*halfWidth[1]
                 + 0.4*rawHalfWidth[2]

count >= 4:
    halfWidth[-1] = 0.1*halfWidth[-4]
                  + 0.2*halfWidth[-3]
                  + 0.3*halfWidth[-2]
                  + 0.4*rawHalfWidth[-1]
```

### 6.3 连续窄点计数与尾锋收尖

原始点数大于 2 后：

```text
if current.halfWidth / maximumWidth < 0.4:
    narrowPointCount += 1
else:
    narrowPointCount = 0
```

注意这里用“半宽除以最大全宽”，因此实际阈值较严格。

若 `isTail` 且仍满足相同窄点条件：

```text
current.halfWidth = 0.03
```

只覆盖平滑半宽，不覆盖 `rawHalfWidth`。这会形成接近尖点的尾锋。

## 7. 二次 Bézier 中心线采样

每次成功加入点后执行。少于 3 个原始点时不采样。

```text
p0 = samples 为空 ? rawPoints[0] : samples.last
p1 = rawPoints[count-2]
p2 = rawPoints[count-1]
```

依据 `p1` 与前一个原始点的距离确定插值次数：

```text
d < 10  -> 4
d < 20  -> 5
d < 40  -> 6
d < 60  -> 8
其他    -> 10
```

若当前输入完成笔迹：

```text
lastIndex = interpolationTimes
interval = 1 / interpolationTimes
```

否则：

```text
lastIndex = interpolationTimes + 1
interval = 0.5 / interpolationTimes
```

对 `index=0..lastIndex`：

```text
t = index * interval
u = 1-t
a = u^2
b = 2tu
c = t^2

position = a*p0.position + b*p1.position + c*p2.position
halfWidth = a*p0.halfWidth + b*p1.halfWidth + c*p2.halfWidth
```

生成样本点。只有与最后样本距离大于 `0.01` 时才追加。

未完成时只消费曲线前半段；下一个原始点到达后，以最后样本作为新 `p0` 继续。完成时采满至 `t=1`，保证中心线到达最终点。

## 9. 三类几何构建

### 9.1 点击

若 `isTap=true` 或只有一个原始点：

```text
outline = placePenCap(rawPoints[0].position, maximumWidth * 0.4)
outlines = [outline]
```

点击宽度固定为最大宽度的 80%（半宽为 `maximumWidth*0.4`），不使用首点的零半宽。

### 9.2 两点短划

把两个点各自的完整笔帽模板点加入候选集，对候选集求凸包：

```text
candidates = cap(point0) + cap(point1)
outline = convexHull(candidates)
outlines = [outline]
```

凸包使用 Andrew 单调链：按 `(x,y)` 排序，构造上下链；当最后三点满足 `cross <= 0` 时弹出中间点。

### 9.3 普通笔迹

```text
samples = stroke.samples.count > 1 ? stroke.samples : stroke.rawPoints
templateSweep = buildTemplateSweepOutline(samples)

if templateSweep.count >= 3 and 所有坐标有限:
    outline = templateSweep
else:
    outline = buildNormalOffsetOutline(samples)

outline = repairRawPointCoverage(outline, rawPoints, samples, completesStroke)
outlines = buildSweepCells(outline, samples)
```

## 10. 模板扫掠完整轮廓

### 10.1 支撑点选择

对单位切线 `t=(tx,ty)`，左法向为：

```text
n = (-ty, tx)
```

遍历模板点 `q`，计算投影：

```text
projection = dot(q, n)
```

- 最大投影点索引为 `forwardIndex`；
- 最小投影点索引为 `reverseIndex`。

它们分别构成中心线两侧的支撑边界。

### 10.2 初始化

```text
initialTangent = direction(samples[0], samples[1])
(initialForwardIndex, initialReverseIndex) = supportIndices(initialTangent)
forwardBoundary = [place(samples[0], template[initialForwardIndex])]
reverseBoundary = [place(samples[0], template[initialReverseIndex])]
```

保存前一切线和前一对支撑索引。

### 10.3 逐线段扫掠

对 `index=0..samples.count-2`：

```text
sample = samples[index]
next = samples[index+1]
tangent = index==0 ? previousTangent : direction(sample, next)
(forwardIndex, reverseIndex) = supportIndices(tangent)
overlap = index>0 and overlapsEarlierSweep(samples, index)
turn = index>0 ? cross(previousTangent, tangent) : 0
alignment = dot(previousTangent, tangent)
```

#### 10.3.1 转角补模板弧

仅当不与早期扫掠重叠，并且：

```text
alignment > -0.9
```

才补角。若：

```text
turn < -0.05
```

在 `forwardBoundary` 上，从旧支撑索引沿模板环走到新支撑索引，补外侧弧，偏好方向为 `(-tangent.y, tangent.x)`。

若：

```text
turn > 0.05
```

在 `reverseBoundary` 上补弧，偏好方向为 `(tangent.y, -tangent.x)`。

选择模板环顺时针还是逆时针的方法：分别计算两条索引路径上的模板点相对中心在 `preferredDirection` 上的最大投影，选择最大投影更大的路径。

#### 10.3.2 生成下一对边界点

```text
forwardPoint = place(next, template[forwardIndex])
reversePoint = place(next, template[reverseIndex])
```

若当前扫掠与早期扫掠重叠：

- `turn < -0.05`：把 `forwardBoundary` 新线段与足够早的历史边界求最近交点，在交点处截断外边界；
- `turn > 0.05`：同理截断 `reverseBoundary`。

历史搜索排除最近约一个模板长度的点：

```text
lastHistoricalIndex = boundary.count - template.count - 2
```

#### 10.3.3 两侧边界交叉修复

追加一对边界点前，分别检查：

- 新 forward 线段是否与 reverse 边界近期部分相交；
- 新 reverse 线段是否与 forward 边界近期部分相交。

近期搜索起点：

```text
max(0, boundary.count - template.count - 1)
```

若两者都相交，采用从各自新线段起点到交点距离更短者。然后：

1. 将被交叉的另一侧边界截断到交点所在历史线段；
2. 向两侧都追加同一个交点；
3. 再正常追加 `forwardPoint`、`reversePoint`。

每次向单条边界追加点时，还要检查新线段是否与该边界近期历史线段自交；若相交，在距离新线段起点最近的交点处截断历史尾部。相邻端点不算交叉。

### 10.4 末端笔帽

若最后样本没有与更早扫掠重叠，则在 `forwardBoundary` 末尾补模板弧：

```text
从 previousForwardIndex 到 previousReverseIndex
preferredDirection = previousTangent
```

若末端已经落入早期扫掠，不补末帽，避免回环处产生多余外凸。

### 10.5 拼接反向边界

把 `reverseBoundary` 倒序拼到 `forwardBoundary`。前 `min(template.count, reverseBoundary.count)` 个拼接点走带自交修复的追加逻辑，其余点只做重复点过滤。

### 10.6 起端笔帽

在首样本处补模板弧：

```text
从 initialReverseIndex 到 initialForwardIndex
preferredDirection = -initialTangent
```

最后删除连续重复点；若末点与首点距离平方不大于 `1e-12`，删除末点。

## 11. 重叠检测

轮廓修复依赖“当前扫掠是否靠近较早扫掠”。所有距离比较优先使用平方距离。

### 11.1 点与早期扫掠重叠

对当前样本 `currentIndex`，只检查到 `currentIndex-2`，跳过直接相邻样本。

对每个早期点：

```text
pointOverlapDistance = current.halfWidth + earlier.halfWidth
if distance(current.position, earlier.position) <= pointOverlapDistance:
    overlap
```

对每个早期线段：

```text
overlapDistance = current.halfWidth
                  + max(earlier.halfWidth, nextEarlier.halfWidth)
```

先用扩张后的包围盒距离做快速排除，再计算当前点到早期线段的最短距离；小于等于该阈值即重叠。

### 11.2 当前线段与早期扫掠重叠

当前线段半宽近似取：

```text
currentHalfWidth = max(current.halfWidth, next.halfWidth)
```

对早期点，检查：

1. 当前起点与早期点距离；
2. 早期点到当前线段距离。

对早期线段，早期半宽取两端最大值，检查：

1. 当前起点到早期线段距离；
2. 两线段的最短距离是否不大于两侧半宽之和；
3. 两线段若实际相交，直接视为重叠。

线段最短距离实现可采用：若相交返回 0，否则取四个端点到另一线段距离的最小值。

### 11.3 点到线段距离平方

```text
pointToSegmentSquared(p, a, b):
    d = b-a
    len2 = dot(d,d)
    if len2 <= 1e-12:
        return distanceSquared(p,a)
    t = clamp(dot(p-a,d)/len2, 0, 1)
    projection = a + t*d
    return distanceSquared(p, projection)
```

### 11.4 包围盒扩张距离

两个轴对齐包围盒间：

```text
horizontalGap = max(0, max(firstMinX-secondMaxX, secondMinX-firstMaxX))
verticalGap = max(0, max(firstMinY-secondMaxY, secondMinY-firstMaxY))
within = horizontalGap^2 + verticalGap^2 <= thresholdSquared
```

## 12. 线段求交

先做包围盒相交检查。设：

```text
P + t*r
Q + u*s
```

```text
denominator = cross(r, s)
if abs(denominator) <= 1e-9:
    无交点

t = cross(Q-P, s) / denominator
u = cross(Q-P, r) / denominator
```

只接受严格位于两线段内部的交点：

```text
1e-6 < t < 1-1e-6
1e-6 < u < 1-1e-6
```

端点接触不作为需要截断的自交，避免合法的连续边界被误判。

交点：

```text
P + t*r
```

## 13. 法向偏移后备轮廓

若模板扫掠少于 3 点或包含非有限坐标，构建普通法向轮廓。

对每个中心线样本：

1. 计算前一线段法向和后一线段法向；
2. 用两法向之和得到连接方向；
3. 计算有限制的斜接偏移。

```text
joinOffset(previousNormal, nextNormal, halfWidth):
    v = previousNormal + nextNormal
    if |v| < 1e-6:
        return nextNormal * halfWidth
    v = normalize(v)
    denominator = abs(dot(v, nextNormal))
    scale = halfWidth / max(0.5, denominator)
    scale = min(scale, halfWidth * 1.6)
    return v * scale
```

左右点：

```text
left = center + offset
right = center - offset
```

轮廓顺序：

1. 左侧从头到尾；
2. 末端圆帽；
3. 右侧从尾到头；
4. 起端圆帽。

圆帽使用 8 段角度插值，不重复两端点。若结束角不大于起始角，加 `2π`；若角差大于 `1.5π`，再减 `2π`，选择较短且方向合适的弧。

## 14. 原始点覆盖修复

Bézier 中心线可能切角，复杂回环也可能使完整轮廓局部漏填。因此构造轮廓后，要检查所有原始点对应笔帽是否被轮廓覆盖。

### 14.1 非零环绕点包含测试

遍历多边形每条边：

- 点到边距离平方不大于 `1e-12`，视为内部；
- 边从下向上穿过测试点水平线且测试点在边左侧，环绕数加一；
- 边从上向下穿过且测试点在边右侧，环绕数减一；
- 最终环绕数不为 0 即为填充区域。

必须使用非零环绕规则，不能改成奇偶规则。

### 14.2 检查原始点笔帽内部

先检查笔帽中心是否已填充。若该原始点可能与早期扫掠重叠，还要检查中心四周半径 `halfWidth*0.25` 的四点：

```text
(center.x+r, center.y)
(center.x-r, center.y)
(center.x, center.y+r)
(center.x, center.y-r)
```

五点都被填充才算完整覆盖。

### 14.3 追加覆盖笔帽

若没有覆盖，将完整笔帽作为一个附加子路径桥接到原轮廓：

1. 计算原轮廓有向面积；
2. 计算笔帽有向面积；
3. 若方向符号不同，反转笔帽遍历方向；
4. 追加原轮廓首点作为桥起点；
5. 追加笔帽起点；
6. 绕笔帽一圈；
7. 再追加笔帽起点和原轮廓首点。

这种桥接让一个点列表表达多个非零环绕子区域。它不要求成为简单多边形。

### 14.4 完成长笔迹的额外检查

当笔迹已完成且原始点不少于 10 个时，从第 3 个 Bézier 样本开始查找第一个与早期扫掠重叠的样本。若其中心没有被完整轮廓填充，则追加该样本的覆盖笔帽，然后停止额外检查。

## 15. 推荐渲染轮廓：扫掠单元

完整兼容轮廓可能包含自重叠或桥接。为了稳定渲染，算法还为每对相邻中心线样本生成一个凸扫掠单元：

```text
for i in 0..samples.count-2:
    candidates = cap(samples[i]) + cap(samples[i+1])
    cell = convexHull(candidates)
```

计算完整轮廓和单元的有向面积。若符号不同，则反转单元点序，使所有输出方向一致。

最终：

```text
outlines = 所有 cell
```

绘制建议：

- 优先逐个填充 `outlines`；相邻单元重叠，视觉上形成连续笔迹；
- 点击和两点短划的 `outlines` 只有一个元素；
- `outline` 主要用于兼容、命中测试或支持非零环绕填充的路径系统；
- 不要描边这些轮廓，只做填充，否则单元接缝会显现。

## 20. 复杂度与工程注意事项

设中心线样本数为 `n`，模板点数固定为 `m=43`。

- 基本采样和普通扫掠约为 `O(n*m)`；
- 重叠检测与边界求交最坏可能达到 `O(n²)`；
- 扫掠单元凸包每段处理 `2m` 个点，因 `m` 固定，可视为 `O(n)`；
- 状态内存主要为原始点、样本和最新轮廓，约 `O(n)`。

工程要求：

- 全程使用双精度浮点；
- 不要用精确相等判断几何点；
- 时间戳必须使用足够大的整数类型；
- 不要在算法层绑定颜色、画刷、路径或视图对象；
- 若跨线程输入，外层必须按状态表访问方式同步；当前算法状态本身不是线程安全容器；
- 同一笔的事件必须按时间顺序串行处理；
- 参数与坐标缩放应一致。若坐标整体放大 `k` 倍，通常应同步放大宽度、最小距离，并按速度单位重新校准 `velocityResponse`；
- 模板顺序、常量、严格不等号和端点容差都会影响复杂笔迹结果，复现时不要随意改写。

## 21. 核心设计总结

该算法本质上由四层组成：

1. **信号层**：过滤无效采样，计算速度、压感宽度并递推平滑；
2. **中心线层**：以增量二次 Bézier 采样降低折线感；
3. **扫掠层**：用固定笔帽模板在中心线上寻找法向支撑点，生成动态宽度双边界；
4. **拓扑修复层**：通过重叠检测、线段求交、边界截断、非零环绕检测和补笔帽，处理回环、自交及漏填。

最终同时输出“完整兼容轮廓”和“相邻样本凸扫掠单元”。前者保存整体几何语义，后者提供更稳定、跨平台且容易实现的填充渲染方式。只要严格实现本文列出的状态转换、宽度公式、模板数据、Bézier 采样、支撑点扫掠和修复规则，即可独立实现完整的笔迹美化算法。
